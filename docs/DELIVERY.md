# 首版交付与验收记录

## 范围

本版本是实际数据驱动的研究 MVP，非模拟行情演示。包含八个页面、三只 ETF 采集、动态游戏发现、事件版本、规则信号、每日存档、Agnes 客户端、自动化部署和测试。

## 已执行本地检查

- Python 3.12 虚拟环境，`python -m pytest -q`：集成测试持续更新，最终数字见提交后的 Actions 记录。
- `npm test`：10 项通过（工具函数 5 项、React 渲染状态 5 项）。
- `npm run build`、`npm run typecheck`：通过。
- Agnes 客户端：27 项模拟测试通过，包括两次 429 后恢复、Retry-After、503、401、超时、非法 JSON、Schema 修复与耗尽。
- 真实采集已经执行，三只 ETF 均获取 2023-01-03 起的行情；具体截止日和条数以 `public/data/latest.json` 为准。
- 本地 Chromium 被执行环境限制阻止启动，未将其计为通过。工作流会使用独立 GitHub runner 运行五项 Playwright 冒烟测试；最终结果以实际 Actions 为准。

## 已实际接入

- Steam 官方公告、商店推荐与 appdetails 动态游戏信息。
- PlayStation Blog、Gematsu、PC Gamer RSS。
- ETF：Eastmoney 日线主源、Sina 备用源；本地实际使用 Sina 成功，主源失败明示。
- Eastmoney 披露期持仓表：三只 ETF 2026 年三季度快照，绝非实时权重。
- Sina 沪深300指数：宽基市场基准，不冒充动漫游戏跟踪指数。
- 上交所官方 2026 年休市公告：显式核验覆盖年限，跨年未更新则暂停。
- 研究配置保存《黑神话：悟空》与《影之刃零》的官方证据和日期修订。

## 已知限制

1. 未核实的经济权益关系不自动建立；当前热门作品可能仅列行业情绪渠道。分批建仓条件因此可能不满足，这是证据门槛而非故障。
2. 动态 Steam 日期可能只有当地显示日期，没有明确时区；保留限制，不把它提升为精确北京时间发售确认。
3. 当前资料不足时不授予 SSS；热度评分是启发式，不是收益概率。
4. 当前持仓表缺公告精确时间，不能用今日得到的持仓回填历史策略；部分表只覆盖部分持仓。
5. Sina 部分字段缺成交额，成交量单位尚需独立核验；不进行跨源量纲拼接。未复权行情不是分红再投资总回报。
6. 两个核心历史事件只能提供描述性对照，2026 年近期事件的 T+20 尚未发生，留空而非推算。
7. 策略从带 recorded_at 的真实历史信号积累，样本不足不展示虚假的胜率；未进行后验参数优化。
8. 版号、监管、上市公司财报全面采集和社区热度仍需扩展；NPPA 页面访问失败未绕过限制。
9. 中文 AI 摘要需要有效 Agnes Secret；无密钥时显示原始来源摘要与明确缺失状态。模拟重试成功不等于真实 AI 请求成功。
10. GitHub 定时任务可能延迟；不会保证准点。2027 年交易日历需核实更新。金融研究结论不保证收益。
